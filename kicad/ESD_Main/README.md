## What is on the board

- 200 x 150 mm, 2 layers, 1.6 mm, GND pour both sides. The PCB is the **front panel**: faders, LCD, D-pad and buttons on top.
- **Three Terwin SM100 motor faders** (footprint from [the datasheet](../../reference/motor_slider_datasheet.pdf)) along the 150 mm depth; each motor hangs through a **26 x 3.2 mm notch** in the back edge. Motor wires go to 2-pin headers MOTOR 1-3 (J10-J12). H-bridges U12/U13 sit between the faders; fader buttons SW8-SW10 beside each fader's front end (no room below them).
- **LCD** (Lab 4 kit: Samsung 16x4, 14-pin single row, no backlight) on 15 mm+ M2.5 standoffs and a tall header **over the bus logic** (8051, '373, SPLD, '273, '244, '14, EEPROM). The LCD lifts off for debugging; the test points are outside its outline.
- Back edge: 12 V barrel (J1), MIDI IN/OUT DIN-5 (J5/J6), pedal TRS (J13). Left edge: PC DB9 (J7). Front: D-pad, RESET, BOOT (PSEN), contrast trimmer, power/status LEDs, TTL PC (J8) and TTL DEBUG (J9) FTDI-style headers, daughter-bus IDC (J14), test points.
- Reference designators differ from the spec's (for example spec U7 SPLD = board U4, spec J10 LCD = board J4); each part's `Note` field in the schematic gives the spec name.

## Check before ordering (needs a person)

1. **Fader footprint**: print the top copper/silk at 1:1 (or use KiCad's 3D/measure) and lay a real fader on it: pins 1/2 and 3/T, the two locating bosses (Ø2.1 NPTH at ±48 mm) and the motor notch.
2. **LCD**: confirm with a ruler: outline 87 x 60, holes 82 x 55 apart, pin 1 at 10.0 mm from the left edge and 2.5 mm from the top. Count 16 vs 20 characters at first power-up (firmware constant).
3. **DIN-5 (Same Sky SDS-50J)** and **barrel jack** orientation: mating faces flush with the back edge (check the 3D view).
4. **Standoffs**: board standoffs >= 16 mm (motor + terminals stick out about 14.5 mm below the top surface); LCD standoffs high enough to clear the socketed DIPs underneath.
5. Run DRC in KiCad, view all copper layers, and look at the motor/12 V traces (1.0/1.2 mm) and the long ADC SPI traces that run under the faders.
6. JLCPCB: upload `fab/ESD_Main_gerbers.zip`; 2 layers, 1.6 mm, HASL lead-free, order a stencil for the 0805 parts.
7. BOM: `fab/ESD_Main_BOM.csv` has MPNs; supplier, URL and cost columns are still blank (course BOM needs them).

## How it was made (and how to change it)

The schematic and the initial board were **generated by scripts** from two data files, then auto-routed with Freerouting 1.9.0:

| File | Role |
|---|---|
| [kicad/tools/esd_main_design.py](../tools/esd_main_design.py) | every part: symbol, footprint, phase, MPN, pin -> net |
| [kicad/tools/esd_main_placement.py](../tools/esd_main_placement.py) | board outline, notches, fixed positions, placement zones |
| [kicad/tools/gen_esd_main.py](../tools/gen_esd_main.py) | writes the schematic (ERC + netlist checked) |
| [kicad/tools/gen_esd_main_pcb.py](../tools/gen_esd_main_pcb.py) | builds, routes (Freerouting) and exports the board |
| [kicad/tools/check_esd_main.py](../tools/check_esd_main.py) | netlist export vs design data cross-check |

```bash
python3 kicad/tools/gen_esd_main.py
KPY=/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3
$KPY kicad/tools/gen_esd_main_pcb.py --stage all --jar /path/to/freerouting-1.9.0.jar --work /tmp/esd_route
```

`--jar` and `--work` default to a path on Nathan's machine, so pass your own. Freerouting needs Java 17+ and is random: each run takes 2-5 minutes and results vary.

**Important**: regenerating overwrites the schematic and board. Once anyone hand-edits in KiCad (routing clean-up, moving parts), stop regenerating the board and make further changes in KiCad (keep the design data file in step for the schematic, or edit the schematic in KiCad too and say so here).
